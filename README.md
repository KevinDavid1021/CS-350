# CS 350: Emerging Systems Architectures and Technologies

## Project Overview

For my CS 350 final project, I developed a prototype smart thermostat using a Raspberry Pi 4. The system used an AHT20 temperature sensor to monitor room temperature, a 16x2 LCD to display information, buttons to control the system, and LEDs to indicate heating, cooling, or idle states. I also implemented serial communication to transmit system information to another computer. The goal was to demonstrate how embedded hardware and software could work together to create a functional thermostat that could eventually be expanded into a commercial product.

## What Did I Do Particularly Well?

I think one of my biggest strengths throughout this project was troubleshooting and getting different hardware components to work together. Earlier in the course, I worked with individual components like LEDs, buttons, and the LCD. By the final project, I was able to combine everything into one functioning system. I also became much more comfortable working through the Linux terminal, testing Python code, and identifying problems when the hardware wasn't responding as expected.

## Where Could I Improve?

One area where I could improve is planning and organizing my code before beginning development. I spent a lot of time troubleshooting throughout the course, and I think having a more structured approach from the beginning would have made some parts of the project easier. I would also like to explore more advanced features, such as remote monitoring and wireless connectivity, to make the thermostat more practical for real-world use.

## What Tools and Resources Am I Adding to My Support Network?

Throughout this course, I gained experience using Raspberry Pi hardware, Python, Linux, SSH, and serial communication tools like PuTTY. I also became more familiar with hardware documentation, Python libraries, and troubleshooting resources. These are tools and resources I can continue using in future programming and embedded systems projects.

## What Skills Will Transfer to Other Projects or Coursework?

The most valuable skills I gained were troubleshooting, hardware and software integration, and working with state machines. Learning how to break down a larger system into smaller components and test them individually will be useful in future computer science courses and software development projects. I also gained a better understanding of how software interacts directly with hardware, which is something I had limited experience with before this course.

## How Did I Make This Project Maintainable, Readable, and Adaptable?

I organized the thermostat software around different operating states and used functions to separate portions of the program's functionality. This made the code easier to follow and troubleshoot. Using Python also made it easier to make adjustments and test changes throughout development. The overall design allows for additional features or hardware components to be incorporated without having to completely rebuild the system.
